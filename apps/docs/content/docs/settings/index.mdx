title: Platform settings
description: Settings of the whole platform.
---

The console's **Settings** page has four sections:

| Section | What it holds |
| --- | --- |
| System | The [control plane URL](/settings/control-plane-url) and the [platform version and updates](/settings/updates) |
| Storage | [Storage profiles](/storage/storage-profiles) and their benchmarks |
| Integrations | [GitHub](/settings/github) |
| Profile | Your [account, password and sessions](/settings/profile) |

<Callout>
  There are no roles yet: every signed-in account can change every setting,
  including starting an update.
</Callout>
